BigQueryのデータロード状態を診断します。以下のコマンドを実行し、結果を日本語で解説してください。

## 実行コマンド

```bash
.venv/bin/python scripts/diagnose_bq_load.py --show-errors 2>&1 | tail -60
```

## 報告内容
1. **ロード状況サマリー**: テーブル別の成功/失敗件数
2. **エラー一覧**: 発見されたエラーと推定原因
3. **対処法の提案**: 問題がある場合の修正手順
4. **次のアクション**: 再実行が必要な場合のコマンド例

問題がない場合は「正常です」と簡潔に報告してください。
